# Franklyn and Adam — measured Flower handoff

Five clients, five rounds, 37 fixed features, class-weighted logistic regression.
Local, federated and pooled results are preserved without alteration.
Raw data and credentials are excluded from this bundle.

The HTML can be opened directly as an offline demo.
The source script expects src/model/ and data/ under the same experiment root; do not run it directly from this handoff directory. Use the pinned data source and hashes provided here to reproduce the experiment.

This is an exploratory comparison, not a demonstrated federated advantage.
